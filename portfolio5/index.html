무엇을 먼저 보고,
어떻게 행동할지 설계합니다.

7년 이상 모바일 앱과 웹 서비스를 설계했습니다. 고객용 앱부터 운영 도구까지, 복잡한 정보와 정책을 이해하기 쉬운 구조로 정리해 왔습니다.

화면을 구성할 때는 사용자가 무엇을 하려는지 먼저 살펴봅니다. 판단에 필요한 정보를 앞에 두고, 다음 행동으로 이어지는 흐름을 만듭니다.

01 사용자 이해
목적과 상황, 실제 업무 흐름을 살핍니다.
02 정보 설계
판단에 필요한 정보의 순서를 정합니다.
03 구현 확인
설계한 흐름이 실제 제품에서도 이어지는지 검수합니다.
